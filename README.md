# Student Management REST API

A CRUD API built using Django REST Framework.

## Features
- Create Student
- Read Student
- Update Student
- Delete Student

## Technologies
- Python
- Django
- Django REST Framework
- SQLite

## API Endpoints

GET /api/students/
GET /api/students/<id>/

POST /api/students/

PATCH /api/students/<id>/

DELETE /api/students/<id>/
